# ArmorSandbox · Web

**Играть:** https://counterstrike2vsco2-hash.github.io/ArmorSandbox/

Браузерная 2D-песочница терминальной баллистики по мотивам мобильной игры *Armor Sandbox*.
Каждая плита, снаряд и осколок — это частицы с реальными свойствами материала (плотность, прочность,
твёрдость, хрупкость, порог откола, температура воспламенения). Пробитие, срабатывание «лома», рикошет,
откол, кумулятивная струя, динамическая защита, детонация и пожар не нарисованы, а считаются.

## Что есть

- **22 боеприпаса:** от 9×19 мм и 7,62 Б-32 до БОПС DM53 / «Манго» / M829A3, каморных снарядов ВМВ
  (ПзГр.39, БР-365, БР-471, M62), ОФ 152 мм, бронебойно-фугасного 105 мм (HESH), ПГ-7ВЛ, тандемного «Корнета»,
  рельсотрона, метеорита и золотого слитка.
- **32 цели:** плиты RHA от 10 до 1000 мм под любым углом, разнесённая и экранированная броня, композит,
  ДЗ, NERA, бетон, кирпич, гель, стекло, бак с водой, бункер и **9 танков в разрезе** (Т-34-85, Tiger I,
  Sherman, ИС-2, Т-72Б, Т-72 с ДЗ, M1A2, Leopard 2A6, БМП-1) с экипажем и боеукладкой.
- **26 готовых опытов** одним нажатием.
- **Конструктор:** кисть, линия, блок, ластик, нагрев, поджиг, заряд ВВ; ~40 материалов; «Пушка» — выстрел
  из любой точки в любом направлении.
- **Редактор материалов:** меняйте плотность, прочность, хрупкость и т.д. на лету.
- Сохранения в браузере, экспорт/импорт файлов, PNG-скриншоты, замедление времени, процедурный звук,
  русский и английский интерфейс.

Управление: `Пробел` — огонь, `P` — пауза, `S` — шаг, `R` — заново, `1–8` — инструменты, колесо мыши — размер кисти.

## Разработка

Чистый JavaScript (ES-модули) без сборки и зависимостей.

```bash
python3 -m http.server 8080      # открыть http://localhost:8080
node test/calibrate.mjs          # калибровка пробития без браузера
node test/snap.mjs 85br365 tiger 0 200   # PNG-кадры сцены в /tmp/snaps
```

| Файл | Назначение |
|---|---|
| `js/engine.js` | физика: сетка ячеек + частицы, эрозия, откол, струи, детонация, тепло |
| `js/materials.js` | база материалов |
| `js/shapes.js` | боеприпасы, мишени, танки в разрезе |
| `js/scenes.js` | компоновка сцены и список опытов |
| `js/render.js`, `js/audio.js`, `js/main.js` | отрисовка, звук, интерфейс |

Модель упрощённая и откалибрована по табличным значениям бронепробиваемости. Это игра, а не инструмент
для проектирования брони. Проект фанатский и не связан с авторами оригинальной Armor Sandbox.
